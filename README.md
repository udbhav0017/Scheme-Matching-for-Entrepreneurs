# Empower India

"Build an accessible, mobile-responsive portal for Indian marginalized entrepreneurs (SC/ST/OBC/Divyangjan/Women). Include:

A multi-step Eligibility Wizard (Annual income, Caste category, Business Sector, State, Loan required).

A Voice-to-Text Input option for low-literacy users.

AI Scheme Matching Dashboard showing Match Percentage Score, estimated subsidy, missing documents, and a 1-click 'Apply Guidance' button.

An AI WhatsApp-like chatbot assistant that answers queries in Hindi and English using RAG on government scheme guidelines."
